#### Change

##### Perception (`src/perception/*`)
- **FAST-LIO2 (`fastlio2`)**:
  - **Dedicated Localization Cloud**: Added `body_cloud_localization` publisher and height filtering (`localization_cloud_enabled: true`, `min_z: -0.20`, `max_z: 1.80`), isolating structural features needed by the localizer and PGO from obstacle costmaps.
  - **Nav2 Obstacle Vehicle Self-Filter**: Implemented `filterNav2VehicleReturns()` in `lio_node.cpp` with configurable vehicle bounding box (`nav2_obstacle_self_filter_*`) and sensor mount patch filtering (`nav2_obstacle_self_patch_*`) to prevent robot chassis and sensor hardware from appearing as obstacles.
  - **TF Future Tolerance**: Added configurable `tf_future_tolerance_s` (0.05 s) to the `odom -> base_link` TF broadcast timestamp to eliminate downstream Nav2 TF extrapolation errors.
  - **Contract Testing**: Updated `lio.yaml` and expanded `test_fastlio2_contract.py` covering dedicated clouds, self-filtering, and TF future tolerance.
- **Perception Interfaces (`interface`)**:
  - **Lifecycle Status Messages**: Added `LocalizationStatus.msg` (tracking 9 states from `UNINITIALIZED` to `LOCALIZED`/`LOST`, scores, overlap ratio, correction rates, and state reasons) and `NavigationStatus.msg` (tracking high-level navigation goals and remaining distance).
  - **Relocalization & Navigation Actions**: Added `GlobalRelocalize.srv` (service for Scan Context descriptor queries) and `NavigateNamedDestination.action` (action for goal navigation in prior map bundles).
  - **Package Configuration**: Added `builtin_interfaces` and `action_msgs` dependencies.
- **LiDAR Localizer (`localizer`)**:
  - **Scan Context Global Relocalization**: Added `ScanContextIndex` (`scan_context_index.h/.cpp`) supporting descriptor extraction, ring-key candidate retrieval, yaw shift optimization, and candidate ranking with score gap validation.
  - **Map Alignment**: Added 2D-to-3D map alignment transformation (`loadMapAlignment`, `m_map2d_from_map3d`) so 3D PCD matching aligns with 2D occupancy maps.
  - **State Machine & Lifecycle**: Implemented active status publishing (`LocalizationStatus` at 5 Hz), tracking sensor staleness, consecutive ICP failures (`max_consecutive_failures: 8`), degraded grace periods, and automatic global relocalization attempts.
  - **Gated Runtime Correction & Planar SE(2) Projection**: Added bounded runtime correction filtering (`correction_alpha: 0.15`, translation limit 0.30 m, yaw limit 0.20 rad) and projected `map -> odom` adjustments onto SE(2) (`candidate_offset_t.z() = 0.0`) to eliminate pitch/roll tilt drift.
  - **Decoupled TF**: Added `publish_tf` and `transform_topic` (`map_to_odom`) support for testing without competing TF broadcasters.
  - **Topic Remapping**: Pointed `cloud_topic` to `/fastlio2/body_cloud_localization`.
- **PointCloud to LaserScan (`pointcloud_to_laserscan`)**:
  - **Vehicle Self-Filter Box**: Added `SelfFilterBox` (`self_filter.hpp`) evaluated in `target_frame` (`base_link`), stripping points within the robot envelope (`self_filter.min_x/max_x/min_y/max_y`) before projecting to LaserScan.
  - **Unit Testing**: Added GTest suite `test_self_filter.cpp` for bounding validation, and added `ament_cmake_gtest` test dependency.
  - **Documentation**: Updated `README.md` with self-filter parameters.
- **PGO & HBA (`hba`, `pgo`, `pgo_gps_fusion`)**:
  - **CMake Modernization**: Configured CMake policy `CMP0074 NEW` across all three packages to eliminate CMake root variable warnings.
  - **PGO Input Remap**: Updated `pgo/config/pgo_slam.yaml` `cloud_topic` to `/fastlio2/body_cloud_localization`.

##### Planning (`src/planning/*`)
- **`global2local_tf`**, **`global_path_planning`**, **`gnss_global_path_planner`**:
  - Removed deprecated `tests_require=['pytest']` argument from `setup.py` across all three packages to eliminate modern setuptools deprecation warnings.
  - File encoding and line endings normalized (UTF-8 BOM added); no functional planning algorithms, node logic, or launch behaviors were modified.

##### Sensor Drivers (`src/sensor_drivers/*`)
- **GNSS & IMU Drivers (`gnss_calibration`, `nmea_navsat_driver`, `wit_imu_traj`, `wit_ros2_imu`)**:
  - Removed deprecated `tests_require=['pytest']` in `setup.py` (`gnss_calibration`, `wit_imu_traj`, `wit_ros2_imu`) to clean up build warnings.
  - File encoding and whitespace normalized (UTF-8 BOM added in `nmea_navsat_driver` and others); sensor message parsing, hardware interfaces, and driver runtime behaviors remain untouched.
- **Chassis Serial Control (`serial_twistctl`)**:
  - **Host Watchdog & Automatic Zero-Velocity Stop**:
    - Replaced the previous 1 Hz periodic logging timer with an active safety watchdog timer executing at `watchdog_period_ms` (default: 100 ms) against `command_timeout_ms` (default: 300 ms).
    - If velocity commands stop arriving within the timeout window, the node issues a throttled warning and actively transmits zero-velocity commands (`vcx=0.000,wc=0.000\n`) to prevent runaway robot motion upon software stalls or lost communication.
    - Added graceful shutdown handling in the destructor to ensure zero velocity is transmitted to the serial bus before closing the serial port.
  - **Acceleration Limiting**:
    - Implemented `limitCommandAcceleration()` helper in `twist_command.hpp` to limit rapid acceleration / magnitude increases while allowing instantaneous deceleration/stopping and ensuring sign reversals pass cleanly through zero.
    - Added configurable acceleration parameters in `serial_twistctl_node.cpp`: `enable_acceleration_limit` (default: false), `max_linear_acceleration` (default: 0.30 m/s²), `max_angular_acceleration` (default: 0.80 rad/s²), and `acceleration_dt_cap_s` (default: 0.10 s).
  - **Serial Communication & Log Throttling**:
    - Refactored `send_command()` helper with partial write error detection (`bytes_written != command.size()`).
    - Reduced high-frequency per-command `[TWIST_RX]` and `[SERIAL_TX]` logging from `INFO` to `DEBUG` and throttled serial write errors, preventing log buffer flooding during active robot navigation.
  - **Automated Testing & Build Configuration**:
    - Added `ament_cmake_pytest` test dependency in `package.xml` and `CMakeLists.txt`.
    - Added GTest suite `test_twist_command.cpp` covering acceleration ramp limiting and direction sign crossings.
    - Added pytest contract test `test_watchdog_contract.py` verifying parameter definitions, watchdog timeout enforcement, zero-command sending, acceleration limiter behavior, and clean shutdown ordering.
