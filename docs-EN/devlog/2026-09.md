  - Seamlessly bridges coarse localizer poses to seed AMCL, and continuously applies bounded SE(2) corrections with strict translation speed (0.015 m/s) and yaw speed (0.006 rad/s) limits, candidate window stability checks (`stable_se2_window`), covariance filtering, and base jump suppression.

  - **Localization Command Gate (`localization_cmd_gate.py`)**: Active watchdog monitoring `/localizer/status`, authority status, and point cloud staleness; fails closed with immediate zero-velocity output upon localization degradation or sensor timeouts, and publishes diagnostics.
  - **Nav2 Collision Monitor (`collision_monitor_travel.yaml`)**: Configured `nav2_collision_monitor` watching `/fastlio2/body_cloud_nav2` with tight `PolygonStop` (footprint e-stop) and `PolygonSlow` (forward slowdown buffer).
  - **Post-Collision Command Conditioner (`post_collision_cmd_conditioner.py`)**: Detects when collision slowdown reduces linear velocity below the vehicle breakaway threshold while turning; zeroes linear motion to prevent motor stalling and wheel scrubbing while preserving angular commands.
